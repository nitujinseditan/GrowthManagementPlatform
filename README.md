## 三、全栈技术选型总览

| 层面 | 技术栈 | 选型理由 |
|------|--------|----------|
| 前端（Web） | React 18 + Next.js 14 (App Router) + Tailwind CSS | 极简UI、SSR/SSG灵活、生态成熟 |
| 桌面端 | Tauri v2 + React | 轻量、安全、跨平台，复用Web代码 |
| 移动端 | React Native (Expo) | 热更新、快速迭代、共享Hooks与状态管理 |
| 状态管理 | Zustand (前端) + TanStack Query | 轻量、无模板代码、服务端状态同步 |
| 后端与API | Node.js + NestJS (TypeScript) | 模块化架构、依赖注入、天然支持微服务 |
| API协议 | GraphQL (Hasura 或 Apollo) | 灵活查询、减少数据往返，适合复杂关联 |
| 数据库 | PostgreSQL 15 + Redis | 结构化数据与成长时间线；缓存与会话 |
| 私密数据加密 | AES-256 字段级加密 + Hashicorp Vault | 零信任架构，用户数据端到端加密 |
| AI教练 | DeepSeek API + RAG (pgvector) + 场景提示词 | deepseek-v4-flash 日常 / deepseek-v4-pro 深度报告 |
| 向量数据库 | pgvector (PostgreSQL扩展) | 避免额外服务，复用现有DB |

| 实时通信 | WebSocket (Socket.io) 或 Supabase Realtime | 社区互动、打卡提醒 |
| 部署 | Docker + Kubernetes (GKE/自建) + Terraform | 弹性伸缩、灰度发布、多环境管理 |
| CI/CD | GitHub Actions + ArgoCD | 自动化测试与部署 |
| 监控/日志 | Grafana + Prometheus + Sentry + OpenTelemetry | 全栈监控、错误追踪 |
| 信任体系防刷 | FingerprintJS + Turnstile + 规则引擎 | 评价真实性保障 |

## 四、关键流程技术细节

### 4.1 私密沉淀端（成长第二大脑）
- **极简记录器**：基于 TipTap / ProseMirror 的块编辑器，支持 Markdown。
- **智能标签**：上传笔记时由 AI 提取标签并自动归类，`pgvector` 做语义相似度推荐。
- **成长时间线**：`milestones` 表按时间轴聚合，前端自定义时间轴组件，支持缩放。
- **数据加密**：笔记写入前使用用户密钥加密（PBKDF2 派生），服务端无明文。

### 4.2 公开社区端（有根分享）
- **有根分享**：帖子关联 `private_entry_id` 溯源，前端展示“原文”卡片（仅作者可见详情）。
- **模板市场**：模板为 JSON（区块类型、样式、默认内容），支持版本控制与导入预览。
- **信任体系**：评价维度 `usefulness`、`ease_of_use`、`recommendation` 加权计分，防刷通过行为分析+人工审核。

### 4.3 AI 成长教练
- **调用链路**：触发复盘 → 后端解密近期记录摘要（最小上下文） → LLM 输出结构化报告。
- **RAG 知识库**：用户历史笔记向量化存入 `pgvector`，语义检索辅助回答。
- **成本控制**：日常用 deepseek-v4-flash，深度报告用 deepseek-v4-pro（MVP 阶段所有用户免费无限使用）。
- **提示词工程**：针对复盘引导、知识诊断设计严格 system prompt，通过反馈迭代。

### 4.4 付费墙与创作者经济（远期设想，MVP 不实现）

> ⚠️ MVP 阶段不引入任何付费机制，以下内容仅供远期参考。

### 4.5 成长报告裂变
- 后端用 Puppeteer / node-canvas 生成可视化报告图，附带用户唯一小程序码。
- 分享追踪通过 URL 参数 `?ref=user_id` 与埋点分析。

## 五、MVP 首发技术决策

1. **先 Web + PWA，原生 App 稍后**：Next.js + PWA 覆盖移动端，React Native 在 V2 推出。
2. **AI 先用 API 直接调用，不做微调**：MVP 仅用 prompt engineering + RAG，积累数据后再微调小模型。
3. **社区从单一垂类（考研）起步**：后台配置化话题分类，避免过早构建通用社区。
4. **Serverless 起步**：Vercel (Web) + Railway/Render (API) 快速部署，量起来后迁移 K8s。
